Hells Balls

A motion-controlled 3D physics bowling game — real rigid-body simulation, USBC scoring, six game modes, and webcam swing tracking.

This is a native desktop game, not a web app. It runs on your own computer via python main.py. It cannot run in a web browser (Panda3D needs an OpenGL window, and the webcam stack has no browser build), so this page is a download & launch hub, not the game itself.

Run it

Requires Python 3.12–3.14 on a desktop machine with OpenGL (a webcam is optional, for webcam mode).

git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
cd YOUR_REPO
pip install -r requirements.txt
python main.py

Controls

Mouse (default)Aim with the pointer, A/D to slide, drag-and-release to throw, sideways drag for hook.
WebcamTAB to toggle (or 1/2), C to switch throwing arm.
MenusMouse, or arrow keys + ENTER (ESC backs out).

Features

Real physicsBall skid/roll/hook, toppling + sliding pins, collisions with restitution, kickbacks — all simulated, never scripted.
Six modesClassic Bowling, Physics Trivia, Equation Challenge, Player vs Bot, Local Multiplayer (2–4), BowlRush.
Webcam trackingMediaPipe pose → swing recognition drives a real throw.
USBC scoringStrikes, spares, and the tenth frame, up to a verified perfect 300.

Why not in the browser?

The game is built on Ursina / Panda3D (a native OpenGL engine) with OpenCV + MediaPipe for webcam tracking. None of those have a WebAssembly/browser runtime, so the game must run on a desktop machine. Making it playable in a browser would require a cloud-streaming setup (running the game on a GPU server and streaming it) or a full rewrite — neither of which preserves the original game unchanged.
